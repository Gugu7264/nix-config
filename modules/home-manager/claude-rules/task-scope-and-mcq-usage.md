# Task Scope and Interactive MCQ Usage Rule

1. **Strictly Confined Scope (No Unasked Side Tasks):**
   - Focus strictly on what was explicitly requested.
   - Do NOT perform unsolicited side tasks or "helpful" cleanup (e.g., adding files to `.gitignore`, reformatting unrelated files, refactoring out-of-scope modules, modifying configuration files that were not asked for).
   - If you notice something that should be cleaned up or added, mention it in text or ask, but do NOT execute it unprompted.

2. **Extensive Use of `AskUserQuestion`:**
   - Make proactive and extensive use of the `AskUserQuestion` tool whenever there are multiple viable implementation paths, architectural tradeoffs, optional cleanup tasks, or key branching decisions.
   - Present structured, action-oriented options with a `(Recommended)` choice so the user can easily guide execution.
